# Changing the Subject of a Formula — Pick-a-Skill Edition

**Mr Nathan's Maths Tuition** · GCSE single-topic series

Choose exactly which skill to practise: all 39 question types are listed in a dropdown, grouped by tier.

**Open it:** https://goyaklaarchimedes.github.io/Topic-ChangingSubject-PickASkill/

## What's inside

- Dropdown of all 39 question types under Foundation, Intermediate and Higher headings
- A new question appears as soon as a skill is chosen
- Option for a random mix of all 39 types
- Running score with percentage, plus a streak badge

## Level

Foundation, Intermediate and Higher. The tiers are cumulative: Intermediate includes Foundation, and Higher includes everything.

## How to use it

Open the link in any web browser on a phone, tablet, laptop or interactive whiteboard. There is nothing to install, and no app, account or subscription is needed.
